# 植物叶片病害识别与可解释诊断 API

## 一、项目背景

农业生产中，叶片病害的早期识别直接影响防治效率和作物产量。传统方式依赖人工经验，存在识别速度慢、主观性强和难以覆盖大量样本的问题。

本项目选择 PlantVillage 数据集中的苹果和番茄叶片，共 8 个类别，目标是完成一套从数据分析、模型训练、实验对比到后端推理接口的完整流程。

## 二、研究目标

1. 使用 NumPy、Pandas 和 Matplotlib 完成数据审计、清洗和可视化。
2. 使用 PyTorch 手写 BasicBlock 和 ResNet18，不使用 torchvision.models 替代手写网络。
3. 比较手写 ResNet18 与 ImageNet 预训练 ResNet18 的迁移学习效果。
4. 对错误样本进行统计和可视化分析。
5. 使用 Grad-CAM 观察模型关注区域。
6. 使用 FastAPI 提供图片上传和 Top-K 分类接口。

## 三、数据集

原始数据来自 PlantVillage 彩色图片目录，使用类别如下：

| 类别 | 说明 |
| --- | --- |
| Apple___Apple_scab | 苹果黑星病 |
| Apple___Black_rot | 苹果黑腐病 |
| Apple___Cedar_apple_rust | 苹果锈病 |
| Apple___healthy | 苹果健康 |
| Tomato___Early_blight | 番茄早疫病 |
| Tomato___Late_blight | 番茄晚疫病 |
| Tomato___Leaf_Mold | 番茄叶霉病 |
| Tomato___healthy | 番茄健康 |

数据审计结果：

- 原始图片：8623
- 完全重复图片：21
- 近重复图片：31
- 损坏图片：0
- 清洗后图片：8571
- 跨标签近重复：3
- 类别不平衡比例：6.865

数据划分：

- 训练集：5996
- 验证集：1284
- 测试集：1291

所有图片均为 256×256、RGB、JPEG 格式。训练集使用 WeightedRandomSampler 缓解类别不平衡，验证集和测试集保持原始分布。

## 四、手写 ResNet18

手写模型包含：

- 7×7 卷积和最大池化组成的 stem；
- BasicBlock；
- 1×1 卷积与 BatchNorm 组成的 downsample；
- 四个阶段 [2, 2, 2, 2]；
- 全局平均池化；
- 全连接分类层。

输入形状：

```text
[B, 3, 224, 224]
```

输出形状：

```text
[B, 8]
```

参数量：

```text
11,180,616
```

训练配置：

- 优化器：AdamW
- 学习率：3e-4
- 权重衰减：1e-4
- 损失函数：CrossEntropyLoss，label smoothing 0.1
- 调度器：CosineAnnealingLR
- 训练轮数：25
- 早停容忍：7

手写 ResNet18 最佳结果：

- 最佳轮次：23
- 验证集 Macro-F1：0.9881
- 测试集 Accuracy：0.9806
- 测试集 Macro-F1：0.9837

## 五、迁移学习对比

迁移学习使用 ImageNet1K_V1 预训练 ResNet18，仅替换分类层，并在相同训练集和验证集上微调。

结果：

- 最佳轮次：2
- 验证集 Macro-F1：0.9965
- 测试集 Accuracy：0.9930
- 测试集 Macro-F1：0.9936
- 实际训练轮数：7，触发早停

结论：

1. 迁移学习收敛更快，使用更少轮数达到更高指标。
2. 手写 ResNet18 的测试集 Macro-F1 达到 0.9837，证明网络结构和训练流程正确。
3. 迁移学习作为对照实验，不替代手写 ResNet 的实现要求。

## 六、错误分析

测试集 1291 张图片中，手写 ResNet18 误判 25 张，错误样本平均置信度为 0.4824。

主要错误组合：

| 真实类别 | 预测类别 | 数量 |
| --- | --- | ---: |
| Tomato___Late_blight | Tomato___Early_blight | 13 |
| Tomato___Late_blight | Tomato___healthy | 2 |
| Tomato___Leaf_Mold | Tomato___Early_blight | 2 |
| Apple___healthy | Tomato___healthy | 1 |
| Apple___healthy | Apple___Apple_scab | 1 |

番茄晚疫病与早疫病存在明显视觉相似性，是最主要的错误来源。后续可以通过增加难例样本、针对性数据增强和更高分辨率输入进一步优化。

## 七、Grad-CAM 可解释性

Grad-CAM 使用最后一个残差阶段的梯度计算热力图，显示模型做出预测时关注的位置。项目对 8 个类别各选择一张测试图片生成原始图和热力图对比，报告保存于：

```text
reports/gradcam/transfer_resnet18
```

## 八、后端接口

使用 FastAPI 提供三个接口：

```text
GET  /health
GET  /model-info
POST /predict
```

预测接口接收图片文件和 top_k 参数，返回：

- 类别英文名称；
- 中文类别名称；
- 概率；
- 推理耗时。

接口输入校验包括：

- 文件类型检查；
- 空文件检查；
- 10MB 大小限制；
- 非法图片解析处理。

## 九、项目不足与改进方向

1. 数据划分仍是图片级随机划分，后续可以按叶片或采集来源分组，减少潜在近重复影响。
2. 番茄早疫病和晚疫病的混淆仍然存在，可以增加局部病斑裁剪与多尺度输入。
3. 当前接口为单模型推理，可以增加手写模型与迁移学习模型切换。
4. 可以增加前端上传页面、预测历史数据库和批量推理。
5. 可以加入 ONNX 导出和推理加速。
